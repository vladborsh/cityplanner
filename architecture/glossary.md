# Глоссарий домена

Один термин — одно значение. В коде используется английское имя. Детали — в `architecture/system-design.md` (номер раздела в скобках).

## Симуляция и ядро

| Термин | Значение |
|---|---|
| **Tick** | Один шаг симуляции = 50 мс игрового времени (§2). |
| **Day / Week** | 4096 тиков / 7 дней. Бюджет списывается раз в неделю. |
| **Movement clock** | Шкала кинематики: `MOVE_SECONDS_PER_TICK = 2.0` секунды движения за тик; скорости агентов, стоимость пути и абстрактные поездки считаются на ней, расписание — на часах суток (§2). |
| **Bucket** | Доля объектов, обрабатываемая за тик: `id.index % N` (§2). |
| **Road run (прогон дороги)** | Максимальная цепочка сегментов через узлы степени 2 с одним типом и высотой, между перекрёстками и тупиками; единица сноса бульдозером (§6.3, v1.2). |
| **Road class (класс дороги)** | `RoadDef.class`: `Local` (2 полосы), `Collector` (4), `Arterial` (6), `Highway` (1–4 полосы, одностороннее, без тротуаров и зонирования). Данные контента, не код (§6.2, v1.3). |
| **One-way (односторонняя дорога)** | Тип, у которого все автомобильные полосы `Forward`; направление движения — направление постройки `start → end`. В M1 только шоссе (§6.6, v1.3). |
| **OneWayWarning** | Предупреждение инструмента дорог, не ошибка: `DeadEnd` (траффику некуда выехать) и `HeadOn` (две односторонние навстречу) (§6.6, v1.3). |
| **DefNames** | Таблица «индекс def-а в сейве → строковый id» в `SaveData`; при загрузке id переназначаются по имени, неизвестные получают заглушку (§12, v1.3). |
| **CityStats** | Производная сводка города для панелей UI (население, зоны, здания, трафик, утилиты, среда, дороги, почасовая история); пересчёт раз в 64 тика, не в сейве и не в чексумме (§13.6, v1.3). |
| **Tool palette / Tool panel** | Левая палитра категорий с иконками и панель инструмента с опциями, списком типов и вердиктом; замена нижней ленты категорий (§13.6, v1.3). |
| **SimRunner** | Владелец sim-`World` и расписания, шагает тики (§2). |
| **SimView** | Read-only снапшот состояния для рендера и UI (§13.1). |
| **SimCommand** | Единственный способ изменить состояние снаружи (§4). |
| **CommandOutcome** | Результат валидации и применения команды: стоимость или ошибка. |
| **CommandLog** | Упорядоченный лог применённых команд; сейв + лог = реплей. |
| **SimRng** | Единственный источник случайности (ChaCha8) с форками по потокам. |
| **SimChecksum** | Хеш состояния раз в 256 тиков для проверки детерминизма. |
| **Arena / Id\<T\>** | Плотное хранилище с поколениями и стабильный id объекта (§3). |
| **SimLimits** | Ёмкости арен и пулов: десктоп или WASM. |
| **ContentDb / *Def** | Загруженные RON-определения: `RoadDef`, `BuildingDef`, `ServiceDef`, `VehicleDef`. |

## Карта

| Термин | Значение |
|---|---|
| **Map** | Каталог с `map.ron`, heightmap, водной маской и картой ресурсов (§5). |
| **Tile** | Квадрат 2048×2048 м. Карта — 5×5 тайлов. |
| **TileOwnership** | Какие тайлы куплены. Строить можно только на купленных. |
| **Sea level / Water mask** | Статичная вода: уровень моря и маска рек и озёр. |
| **Outside connection** | Точка на краю карты, через которую въезжают и выезжают (§5, M3). |

## Сеть

| Термин | Значение |
|---|---|
| **Node** | Точка сети: перекрёсток, конец, промежуточная точка или внешняя связь. Максимум 8 сегментов (§6.1). |
| **Segment** | Кривая Безье между двумя узлами с типом дороги и полосами. |
| **RoadDef** | Тип дороги: профиль полос, скорость, стоимость, зонирование, варианты высоты. |
| **Lane** | Полоса сегмента: тип (машины, пешеходы, трамвай…), направление, смещение. |
| **LaneConnection** | Проезд с полосы на полосу через узел, со своей кривой и конфликтами. |
| **Junction** | Узел, где сходятся ≥ 3 сегментов либо 2 сегмента под углом. |
| **JunctionControl** | `Priority` или `TrafficLight` с фазами (§6.5). |
| **Elevation** | `Ground`, `Elevated`, `Bridge` или `Tunnel` (M3). |
| **Access point** | Точка подключения здания к сегменту: `segment`, `s`, `side`. |
| **Congestion** | Загрузка сегмента: мгновенная и EMA (§9.4). |

## Зоны и здания

| Термин | Значение |
|---|---|
| **ZoneType** | `ResLow`, `ResHigh`, `ComLow`, `ComHigh`, `Industrial`, `Office` или `None`. |
| **ZoneBlock** | Сетка ячеек с одной стороны зонируемого сегмента (§7). |
| **Frontage (фронт)** | Одна сторона улицы между двумя поперечными улицами этой стороны: цепочка сегментов через узлы степени 2 и через перекрёстки на стороне без примыкания; единица раскладки ячеек v2 — шаг вдоль и глубина рядов подгоняются к кромкам поперечных и фасадной улиц (§7.1, v6.1). |
| **Block lattice (решётка квартала)** | Общая сетка `c_u × c_v` прямоугольного квартала от его угла: фронты квартала раскладываются на неё, угловые ячейки совпадают, ячейка принадлежит ближайшей кромке (§7.1, v6.1). |
| **ZoneCell** | Ячейка 8×8 м. Валидна, если ничем не перекрыта. |
| **Lot** | Прямоугольник 1–4 × 1–4 ячеек у дороги под одно здание. |
| **Building** | Экземпляр `BuildingDef` на лоте или на свободном месте (сервисы). |
| **Level** | Уровень здания: 1–5 у жилья, 1–3 у остальных (§8). |
| **Level progress** | Накопленный прогресс к следующему уровню. |
| **Problem flag** | Активная проблема здания: нет воды, нет электричества, нет работников… |
| **Abandoned** | Здание, у которого проблема длится 7 игровых дней. |
| **Service building** | Здание, поставленное игроком: насос, электростанция, позже школа. |

## Население и движение

| Термин | Значение |
|---|---|
| **Citizen** | Запись жителя: возраст, образование, дом, работа, местоположение (§9.1). |
| **Household** | Группа до 5 граждан с общим жильём. |
| **Trip** | Поездка гражданина: откуда, куда, цель, режим. |
| **Mode** | Способ передвижения: `Walk`, `Car`, позже `Transit`, `Bike`. |
| **Agent** | Физическое представление поездки: `Vehicle` или `Pedestrian` из пула. |
| **Abstract trip** | Поездка без агента (пул полон или агент исчез). Прибытие по стоимости пути. |
| **Path** | Последовательность `LaneConnection` от начальной до конечной точки доступа. |
| **Path request** | Запрос поиска пути. Результат применяется ровно через 8 тиков (§2). |
| **Stuck despawn** | Удаление машины, стоящей дольше порога (§9.4). |

## Утилиты и экономика

| Термин | Значение |
|---|---|
| **Utility network** | Сеть труб (вода, канализация) или ЛЭП (§10). Вода и канализация идут по одной трубе — одна сеть, две ёмкости: насосы дают воду, стоки отводят (v1.4). |
| **Supply** | Снабжено ли здание ресурсом в этом цикле распределения. |
| **Capacity** | Производство источников; распределяется BFS по возрастанию id. |
| **Demand (RCIO)** | Спрос −100…100 на жильё, коммерцию, индустрию и офисы (§11). |
| **Land value** | Стоимость земли на сетке 64 м. |
| **Pollution / Noise** | Сетки 64 м: загрязнение почвы и шум. |
| **Budget** | Доходы (налоги) минус расходы (содержание) за неделю. |
| **Milestone** | Порог населения, открывающий контент и тайлы (M2). |

## Поздние вехи

| Термин | Значение |
|---|---|
| **ServiceCoverage** | Покрытие сервисом: по виду сервиса значение `[0, 1]` на сегмент дороги = `1 − d / radius_m` от ближайшего здания вида по графу сегментов; производное, пересчёт раз в 64 тика (§16 M2, v2.0). |
| **Daily capacity (суточная ёмкость)** | Сколько единиц (мусора, больных, тел, преступности) сервисное здание обрабатывает за игровые сутки; у образования — мест, у пожарных — машин одновременно (§16 M2, v2.0). |
| **ServiceProblems** | Битовое поле проблем сервисов здания: мусор, больные, умершие, пожар, преступление; отдельно от `BuildingFlags` (§16 M2, v2.0). |
| **Service vehicle** | Мусоровоз, скорая, полиция, пожарные — физические агенты; в M2 сначала абстрактно, машины — T-151. |
| **District tax override** | Своя ставка налога района для типа зоны; без неё действует городская (§16 M2, v2.0). |
| **Loan (кредит)** | Предложение банка (сумма, процент на весь срок, срок в неделях, порог населения); погашается равными недельными платежами, досрочно — остатком долга без штрафа (§16 M2, v2.0). |
| **TransitLine / Stop** | Линия общественного транспорта и её остановки (M3). |
| **District** | Нарисованная кистью по сетке 32 м область с именем и цветом; налоги — M2 (v2.0), политики — M4. |
| **Policy** | Модификатор систем в районе или городе (M4). |
| **Unique building / Monument** | Особое здание с условиями разблокировки и бонусами (M4). |
| **IndustryArea** | Индустриальная зона ресурса с главным зданием и уровнем (M5). |
| **Production chain** | Добыча → переработка → склад → фабрика (M5). |
| **ParkArea** | Парковая зона с воротами, уровнем и посетителями (M6). |
| **Entry road (въездное шоссе)** | Пара односторонних шоссе от точки внешней связи на краю карты до перекрёстка с примыканием в стартовом тайле; строится симуляцией на новой игре по `MapMeta.entry_road`; новые жители въезжают только по нему (§5.1, v1.4b). |
| **Free-standing building (отдельностоящее здание)** | Сервисное здание с `road_access: false`: стоит на свободном прямоугольнике без дороги и без ячеек зоны, подключается к сетям по радиусу (§8.1, v1.4b). |
| **Style (стиль здания)** | `StyleDef` — форма, крыша, этажность, палитра, фасад и детали; у def-а несколько стилей, вид конкретного здания выбирается хешем его `BuildingId` (§8.2, v1.4b). |
| **Stretch (участок)** | Цепочка сегментов через узлы степени 2 одного типа и высоты без угла (поворот касательной > 10°); граница — перекрёсток, тупик, угол, смена типа. Подмножество прогона; производная функция `cp_net::stretch`, не хранится (§6.7, v1.4c). |
| **Control point (контрольная точка)** | Метка на участке каждые 64 м (8 ячеек) от его якоря; направляющая инструмента дорог и остановка бульдозера. Не узел графа, не в сейве и не в симуляции трафика (§6.7, v1.4c). |
| **Cell step (шаг ячейки)** | Длина дороги, построенной инструментом, кратна 8 м — ячейке зоны; квантование делает инструмент, команда получает готовые координаты (§6.7, v1.4c). |
| **Run (рейс)** | Поездка машины или пешехода из общего пула по заказу домена, а не гражданина: сервисная машина (T-151), автобус и поезд (постоянная машина со стоянками), грузовик, турист, пешее плечо пассажира. Механизм `cp_traffic::runs`; пул полон — рейс абстрактный (§16 M3, v3.0). |
| **Line (линия)** | Кольцо остановок одного режима (`Bus`, `Metro`, `Train`) с числом машин; маршрут между остановками — производный путь A*, пересчитывается при изменении сети (§16 M3, v3.0). |
| **Stop / Station (остановка / станция)** | Точка посадки линии: остановка — на тротуаре сегмента дороги; станция — здание у дороги с собственной платформой-сегментом пути под собой (метро) или на земле (вокзал) (§16 M3, v3.0). |
| **Journey (путь пассажира)** | План поездки общественным транспортом: пешком до остановки, ожидание, одна или две поездки (пересадка), пешком до цели; выбирается сравнением оценки времени с пешком и машиной (§16 M3, v3.0). |
| **Headway (интервал)** | Время круга линии, делённое на число машин; половина интервала — оценка ожидания (§16 M3, v3.0). |
| **Goods (товары)** | Запас здания I или C: индустрия производит, коммерция расходует, грузовики возят; нет поставщика — импорт, нет покупателя — экспорт через Outside (§16 M3 (D), v3.0). |
| **Policy (политика)** | Переключатель города или района (`PolicyKind`), меняющий число в системе-потребителе по позиции здания; стоит `cost_per_building_week` за каждое здание под ней (§16 M4, v4.0). |
| **Specialisation (специализация)** | Выбор района для типа зоны (`SpecKind`): там спавнятся только спец-здания этого вида, несовпадающие перестраиваются (§16 M4, v4.0). |
| **Unique building / Monument (уникальное здание / монумент)** | Отдельностоящее здание, одно на город, открывается условиями `UnlockCond` навсегда; даёт стоимость земли (`LandEffect`) и туристов; монумент открывается числом построенных уникальных (§16 M4, v4.0). |
| **Area (область)** | Клетки второй сетки 32 м `cp_district::AreaMap` с видом `AreaKind`: индустриальная область ресурса (M5) или парковая область вида парка (M6); перекрывается с районами свободно (§16 M5, v5.0). |
| **Resource map (карта ресурсов)** | `resources.png` карты: богатство плодородия, леса, руды и нефти на клетку 64 м; руда и нефть истощаются (`ResourceDeposits`) (§16 M5, v5.0). |
| **Cargo (груз)** | Вид груза цепочки индустрии (`CargoKind`; `Goods` — товары M3), возится рейсами грузовиков, поездами и кораблями (§16 M5, v5.0). |
| **Cargo hub (грузовой узел)** | Грузовая станция или порт: через ближайший узел идут экспорт и импорт вместо шоссе; поезд или корабль забирает и привозит груз партиями (§16 M5 (E), v5.0). |
| **Leisure target (цель досуга)** | Запись `cp_citizen::LeisureTargets` (ворота парка, городской парк, уникальное здание) с весом; её заполняет `cp_park`, по ней выбирают цель поездки досуга жители и туристы (§16 M6, v6.0). |
| **Park level (уровень парка)** | 1…5 по накопленным посетителям области; открывает аттракционы и поднимает стоимость земли вокруг (§16 M6, v6.0). |
