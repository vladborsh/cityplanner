# Окно «Власть»: переделка UI коррупции (T-335, 2026-10-29)

Задача пользователя 2026-10-29: окна «Предложения» и «Ось коррупции» нагружены и сумбурны.
Нужно: иконки вместо слов, секции, правильное разделение «на виду / во всплывающем»,
инфографика вместо текста. Механика (`corruption.md`) **не меняется**; это UI в `cp_ui` плюс
три поля в производной истории `CityStats` (не сейв, не чек-сумма).

- Было: `.data/coord/shots/T-335-before.png` (town:2000, `--lang ru`, `--open offers,axis`).
- Макет (интерактивный, вкладки, предпросмотр «Принять», тумблер тендеров, твики «аудит» и
  «пресса»): https://claude.ai/artifact/9XDvL7RiabSAyxiCmX4EXW — артборды «Стало: окно
  «Власть»» и «Стало: кнопка, тосты, тултипы». Цвета, размеры и шрифт в макете —
  ориентир; в игре берём тему egui и `palette.rs`.

## 1. Что не так сейчас

1. Окно оси — около 35 строк текста, не влезает в 1000 px по высоте.
2. Повторы: доверие, институты и «слухи» есть в обоих окнах; «Риск: сделки всплывают на 50%
   чаще» трижды.
3. Шкала оси 320 px, уже окна; подпись «Правовое государство» не над концом полосы; нет засечек
   ±`edge`.
4. Карточка сделки — абзац из строк одного цвета; срок ответа бледным текстом.
5. Иконка «Предложений» — `OverlayMail`, та же, что у оверлея «Почта».
6. Нигде не видно накопленного риска скандала (улики × раскрываемость × крыша).
7. Риск подкупа полиции — последней строкой окна оси.

## 2. Новая структура

### 2.1 Верхняя панель
Кнопки `UiWindow::Offers` и `UiWindow::Axis` заменяются одной **`UiWindow::Power`** («Власть»),
новая иконка `window_power` (колонны). На кнопке:
- бейдж с числом предложений (как сейчас у Offers);
- полоска доверия 3 px внизу кнопки: зелёная, ниже 50 — жёлтая, ниже 30 — красная.

`UiWindow::parse("offers"|"axis")` → `Power` (старые `--open` и сохранённые наборы окон
продолжают работать); варианты `Offers`/`Axis` удалить или оставить алиасами: решает dev, лишь
бы `--open offers` открывал новое окно на вкладке «Предложения», а `--open axis` — на шапке.
Все действия `Action::Window(Offers|Axis)` (советник, жалоба `Distrust` в `happiness.rs`)
ведут в `Power` с нужной вкладкой.

### 2.2 Окно «Власть»: шапка (видна на любой вкладке)
1. **Три плитки в ряд:**
   - **Доверие** — число / потолок, полоса с засечкой потолка (`trust_ceiling`).
   - **Коррупция** — число с Аудитом; без него — фраза-слух (`offers::rumour`) в кавычках.
   - **Институты** — число и спарклайн (§3.3).
2. **Ось** на всю ширину окна:
   - слева кланы (иконка-корона, красный), справа право (весы, синий), середина серая;
   - засечки на ±`edge`, подписи «край +40 / серая середина / край −40»;
   - город — вертикальный маркер (с Аудитом) или полупрозрачная полоса ±`GUESS` (без него);
   - текст `edge_text` — короткий, между подписями краёв.
3. **Строка риска:** «Риск скандала» + шкала из 5 сегментов (§3.1), справа чипы «улик: N» и
   «прикормлено: N» (без Аудита «?»).

### 2.3 Вкладки
**Предложения** (с бейджем), **Институты**, **Скандалы**. Выбранная вкладка помнится в
`PanelState` (не в сейве).

- **Предложения.** Карточка на сделку:
  - иконка вида сделки, имя, цель (район или здание) мелким;
  - кольцо обратного отсчёта «N дн»: зелёное, ≤5 дн — оранжевое, ≤3 — красное;
  - ряд чипов: выгоды (зелёные) — деньги, /нед, стройка −%, дни, снятый запрет, туристы,
    доверие+; цена (оранжевые) — `C +n`, улика точками ●●○, доверие−, загрязнение,
    криминал;
  - кнопки «Принять» и «Отказать», рядом — что даёт отказ («доверие +1» с прессой, «доверие −1»
    на краю кланов, иначе «отказ ничего не даёт»);
  - описание сделки (`def.text`) — в тултипе значка ⓘ у имени;
  - пусто — одна строка «Предложений нет…», как сейчас.
- **Институты.**
  - Три плитки в сетке: иконка здания (`audit_chamber`, `free_press`, `court`), имя, статус
    («Стоит» / «Можно построить · цена» / «🔒 с N жителей»), чипы `I +n`, `риск +n%` и один
    главный плюс.
  - «Сейчас / Потом / Риск» (`axis::institution_terms`) — в тултипе плитки, с иконками ▶ ⏳ ⚠.
  - Клик по плитке «Можно построить» выбирает здание в палитре (как клик в меню построек).
  - Под плитками строка «Прозрачные тендеры» с чипами и **переключателем**. Он шлёт ту же
    команду политики, что окно «Политики города»; это команда, не прямая запись в сим.
- **Скандалы.**
  - Лента времени за последние 90 дней: точка на день скандала, высота штриха ∝ `trust`,
    полное описание (`offers::scandal_text`) — в тултипе.
  - Ниже — список улик (`CorruptionState::evidence`): имя сделки, день, вес точками. Это
    единственное место, где видно, *что именно* может всплыть.

### 2.4 Всплывающее
| Что | Как |
|---|---|
| Плюсы и минусы краёв (`clan_lines`, `law_lines`) | тултип на подписи края оси |
| `C − I = a` | тултип на маркере (только с Аудитом) |
| «Без палаты место — догадка» | тултип на полосе-догадке |
| Разбор риска скандала | тултип шкалы риска: три полосы (вес улик; раскрываемость, сложенная из базы/аудита/прессы/суда; крыша) |
| Риск подкупа полиции (`police_terms`) | тултип чипа «прикормлено» |
| Новое предложение | тост (снэкбар советника): имя, цель, 2–3 чипа, «Открыть» → вкладка «Предложения» |
| Скандал | тост с красной рамкой: «Всплыла …», чипы доверия и штрафа, «отменена», «Открыть» → «Скандалы» |

Тосты — через существующий `advisor_snackbar` (новый `Severity` не нужен, если рамку можно
задать по `id`; иначе — `Severity::Warning` для скандала). Тост предложения — по появлению
нового `Offer` в `inbox`, скандала — по новому элементу `scandals` (сравнение с прошлым кадром
в UI-ресурсе, не в симе).

## 3. Инфографика

### 3.1 Риск скандала: 5 сегментов
UI-оценка того же, что бросает сим (`cp_economy::corruption`, §6):
`p = scandal_day × Σ weight × exposure × (1 − roof)`.
- Если в `cp_economy` есть чистая функция шанса — звать её. Нет — вынести расчёт в
  `pub fn scandal_chance(&CorruptionState, &CorruptionKnobs) -> f32` в `cp_economy` и
  использовать её и в симе, и в UI: одна формула, без копии.
- Сегменты — по порогам шанса **в день**. Стартовые пороги `[0.002, 0.005, 0.01, 0.02, 0.04]`
  — константы в `cp_ui`, `// tune later`.
- Без Аудита число не показывать: сегменты видны, тултип пишет «примерно».
- Во время скандальной паузы (`scandal_cooldown_until`) шкала тусклая, в тултипе «следующий
  скандал не раньше дня N».

### 3.2 Предпросмотр «Принять»
Пока курсор на «Принять»:
- на оси — второй, оранжевый маркер в `a + deal.corruption` (без Аудита — сдвинутая полоса);
- на шкале риска — сегменты, которые добавит улика `deal.evidence`: штриховые, светлее.

Чистая функция над копией `CorruptionState` в UI; сим не трогается.

### 3.3 Спарклайн C / I / доверия
В `cp_sim::stats::HistorySample` три поля: `corruption`, `institutions`, `trust`. Они
заполняются в том же месте, что и остальные сэмплы, из `CorruptionState` / `trust_now`.
`CityStats` производный: не в `SaveData`, не в чек-сумме — сейв не бампается.
Рисуется `metrics::sparkline` в плитке «Институты» (три линии, цвета как у плиток); без
Аудита линии коррупции нет.

## 4. Иконки
Новые SVG — в `assets/ui/icons/src`, рендер `tools/assets/icons.mjs`, варианты в `icons!`.
Квадратные, единого стиля, у каждой своя (правило пользователя). Уже есть и переиспользуются:
`audit_chamber`, `free_press`, `court`, `policy_transparent_tenders`, `overlay_police`,
`overlay_pollution`.

| Стем | Смысл |
|---|---|
| `window_power` | окно «Власть» (колонны) |
| `trust` | доверие (рукопожатие) |
| `corruption` | коррупция (конверт с купюрой) |
| `institutions` | институты, если отличаются от `window_power` (иначе то же) |
| `evidence` | улика (папка) |
| `scandal` | скандал (газета с молнией) |
| `captured` | прикормленный участок (щит с монетой) |
| `deadline` | срок (песочные часы) |
| `edge_clan`, `edge_law` | края оси (корона / весы) |
| `term_now`, `term_later`, `term_risk` | ▶ ⏳ ⚠ |
| `deal_money`, `deal_build`, `deal_ban`, `deal_tourists`, `deal_crime` | чипы эффектов |

Иконки видов сделок для плитки карточки — по полю эффекта (стройка, запрет, деньги,
загрязнение, туристы); новое поле в `DealDef` не нужно.

## 5. Что удаляется или переезжает
- `offers::offers_window` и `axis::axis_window` → один `power::power_window`. Чистые функции
  (`terms`, `standing`, `rumour`, `scandal_text`, `institution_terms`, `clan_lines`,
  `law_lines`, `police_terms`, `hints`) остаются и кормят тултипы. `terms` дополнительно отдаёт
  структурированные чипы (вид, текст, плюс/минус) вместо строк «Сейчас: …».
- Подсказки советника про институты (`axis::hints`, `hint_audit|press|court`): вместо
  «{name} можно построить. {now}. {later}. {risk}.» одна строка «{name} можно построить:
  институты +n, сделки всплывают чаще.» и действие «Открыть» → вкладка «Институты».
- В бюджете полиции слайдера по-прежнему нет; риск подкупа живёт в тултипе чипа «прикормлено».
