# Asset licences

Only CC0 or self-made assets are allowed in this repo. Every imported pack is listed here in the
same commit that adds its files; every file under `assets/models/` appears in a table below
(checked by the `cp_desktop` gallery test).

Converted files are derived from the source models by `tools/assets/import_assets.mjs`
(skeleton and animations removed, rest pose baked, decimated to the triangle budget, scaled to
metres, pivot at ground centre, +Y up, +Z front). Source packs are not committed.
