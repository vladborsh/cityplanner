# Asset licences

Only CC0 or self-made assets are allowed in this repo. Every imported pack is listed here in the
same commit that adds its files; every file under `assets/models/` appears in a table below
(checked by the `cp_desktop` gallery test).

Converted files are derived from the source models by `tools/assets/import_assets.mjs`
(skeleton and animations removed, rest pose baked, decimated to the triangle budget, scaled to
metres, pivot at ground centre, +Y up, +Z front). Source packs are not committed.

## Sounds

### Self-made sound effects (T-189)

- Author: this project (generated by `tools/assets/gen_sounds.py`: sines, filtered noise and decaying

- Licence: CC0 1.0 Universal; no third-party material

(`assets/ui/icons/src/*.svg`) and are rendered by `tools/assets/icons.mjs`
(`@resvg/resvg-js`). They are dedicated to the public domain under CC0 1.0 Universal
(https://creativecommons.org/publicdomain/zero/1.0/). No third-party icon pack is used.

## Fonts — SIL Open Font License 1.1 (T-184, exception to "CC0 only", approved by the user 2026-10-16)

Symbol fallbacks for egui (warning, tick, cross, arrows, money, people, parallel/perpendicular
signs), embedded with `include_bytes!` by `cp_ui::style`. Subsets of the upstream fonts made with
`pyftsubset --no-hinting` (glyph ranges below); the licence text is `assets/fonts/OFL.txt`. The
fonts are not renamed-reserved; the subset keeps the upstream family names and is not sold.

- `assets/fonts/NotoSansSymbols2-subset.ttf` — Noto Sans Symbols 2 (The Noto Project Authors),
  https://github.com/notofonts/symbols, OFL 1.1. U+2190–21FF, U+23E9–23FA, U+25A0–25FA and
  U+25FC–25FF (U+25FB is left out: it is egui's replacement glyph), U+2600–26FF, U+2700–27BF, U+2B00–2BFF, U+1F4B0.
- `assets/fonts/NotoSansMath-subset.ttf` — Noto Sans Math (The Noto Project Authors),
  https://github.com/notofonts/math, OFL 1.1. U+2200–22FF, U+263B.
- `assets/fonts/NotoSans-Bold-subset.ttf` (T-274) — Noto Sans Bold (The Noto Project Authors),
  https://github.com/notofonts/latin-greek-cyrillic (the static hinted TTF from
  https://github.com/notofonts/notofonts.github.io, `fonts/NotoSans/hinted/ttf/NotoSans-Bold.ttf`),
  OFL 1.1. The text face of the menus and panels. U+0020–007E, U+00A0–017F, U+0400–04FF,
  U+2010–2027, U+2030–205E, U+20A0–20BF, U+2116, U+2122. Its copyright line is added to
  `assets/fonts/OFL.txt` (the licence text is the same).

T-331c adds the overlay icon `overlay_parking` (a white P on a blue sign): self-made SVG (`assets/ui/icons/src/overlay_parking.svg`), CC0, same pipeline.
