# Cityplanner

3D-градостроитель в духе Cities: Skylines 1 на Rust и Bevy: свободные дороги на кривых Безье,
зоны, сети воды и электричества, сервисы, транспорт и агентный трафик.

**Играть в браузере:** <https://vladborsh.github.io/cityplanner/>. Сборка выкладывается
сама после каждого зелёного коммита в `master`.

- Как собрать и играть на компьютере: [`docs/PLAYING.md`](docs/PLAYING.md)
- Сетап для разработки: [`docs/SETUP.md`](docs/SETUP.md)
- О проекте и процессе: [`PROJECT.md`](PROJECT.md), правила для агентов: [`AGENTS.md`](AGENTS.md)
