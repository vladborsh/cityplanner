All construction/build tool icons (roads, zones, buildings, pipes, lines, bulldozer…) must be **square and uniform** — same size, same frame, same style. Every building/tool has its **own distinct icon** (recognisable silhouette, not a recolour of one shape). Water and Power are **sections inside the Buildings panel** (pipe + pump + outflow in one Water section), not separate palette categories.

**Why:** user playtest 2026-10-15: "мы делаем игру, всё должно быть визуально понятно и красиво"; road-panel icons (procedural profile strips, T-083) looked "very strange".

**How to apply:** put this rule into every UI/icon brief and Architect amendment; reject UI reviews with non-square, mixed-shape or duplicated icons. Related: [[merge-wait-grep]]
